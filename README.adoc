cl-adoc is an AsciiDoc parser and HTML5 renderer for Common Lisp.

The project is new. Some interfaces and behavior can change.

cl-adoc reads an AsciiDoc file into a document tree. It renders that tree in a
separate step.

This separation lets a program inspect a document without rendering it. For
example, a program can read document attributes, build a table of contents, or
check image paths before it creates HTML.

The document tree does not store the original markup. Rendering is one pass over
the tree.

== Installing

cl-adoc is distributed with ocicl. From a project directory, run:

----
ocicl install cl-adoc
----

To use unreleased changes, clone this repository into a directory that ASDF
searches. Then load the system from that directory.

== Using it

[source,lisp]
----
(asdf:load-system :cl-adoc)

(defparameter *document* (adoc:parse-file "example.adoc"))

(adoc:node-text (adoc:document-title *document*))
(adoc:document-attribute *document* "date")
(adoc:render-html *document*)
----

Parsing and rendering are separate operations. You can get information from a
document without rendering it.

For example:

[source,lisp]
----
(adoc:document-headings *document*)     ; headings for a table of contents
(adoc:heading-id heading)               ; anchor used by the HTML renderer
(adoc:document-uses-stem-p *document*)  ; true if the document uses stem content
(adoc:document-references *document*)   ; link and image targets
----

Use these functions to walk the full tree:

[source,lisp]
----
(adoc:map-nodes ...)
(adoc:collect-nodes ...)
(adoc:find-node ...)
----

They visit block nodes and inline nodes.

== Supported AsciiDoc

SPEC.adoc describes the AsciiDoc features that cl-adoc supports.

It also lists features that cl-adoc does not support, and explains why they are
not supported.

SPEC.adoc is versioned separately from the library. Its markers show which
parts are implemented.

== Requirements

cl-adoc is built and tested on SBCL.

The tested SBCL versions are the versions packaged by Ubuntu 24.04 and Ubuntu
26.04:

* SBCL 2.2.9
* SBCL 2.6.0

Other Common Lisp implementations are not tested.

Building cl-adoc requires ocicl.

== Security

Use cl-adoc with documents that you control.

cl-adoc writes link targets and image targets to the output as they appear in
the source document. For example, a source document can contain a link target
that starts with `javascript:`. cl-adoc does not remove or change that target.

If you render documents from another source, filter link targets and image
targets yourself. You can filter them before rendering, or you can filter the
HTML after rendering.

== Stability

cl-adoc is a 0.x library.

The Lisp interface can change between releases.
